# LondonCrimeLocator
Made for a 'Superhero' themed hackathon.
Small Java program that maps crimes in an area of London. Allows users to aid other users that have sent aid requests. Uses official police data. 

Requires access to a https://jsonbin.io/ account, and must then place your own  json access key under the file name *JSON-AcessKey*..

Compile code using supplied libraries and then execute program
